# 资料核对工作台

入口为 `/materials.html`，与采购工作台共享当前合成租户。采购材料可来源于文本、VTT会议字幕或OCR分析JSON；合同、订单和产品资料使用独立外贸字段，不进入采购Plan。

## 操作

1. 选择采购材料或外贸单据，导入文件或载入合成样例。
2. 保存材料，展开页码/区域或时间段，核对字段候选。
3. 明确确认、修正或忽略每个字段；修正、缺项补充、忽略需至少三字理由。保存人工核对。
4. 采购资料一致后，显式创建未批准草稿，再到采购工作台确认与执行。外贸差异保留各资料值，可导出核对包交接。
5. 刷新读取服务端最新版本。报告关联状态每次重新查询运行版本与哈希。

编号缺失时可以使用页面生成的候选编号，仍需保存人工核对。字段修改未保存时，草稿创建和报告导出均禁用。提案结果不确定时只查询原编号；同源同浏览器会话共享Web Lock与待核对标记，页面重载也不重发。该保护不代表跨设备服务端提案幂等；登记效果去重仍由原后台契约负责。浏览器不支持锁或无法保存标记时不发送材料提案。

## 文件与范围

OCR分析JSON格式见 [来源格式](architecture/material-source-format-2026-10-11.md)，保留上游原件哈希、声明的解析引擎、页码及归一化区域；可选PDF/图片只在本机计算哈希，不上传原件。哈希匹配不是识别准确率或服务端认证。

VTT实际解析时间码、多行文本和重叠字幕；不会运行音视频转录。扫描OCR及ASR引擎属于上游解析服务，本版本没有下载模型或调用识别引擎。合成OCR样例明确标为夹具。

一次1–3份材料、每源最多4000字/40段、文本单行最多500字、每租户最多30案例；现有API 12KB请求体限制保持，超限需拆分材料。数量和包装不换算；外贸币种限定USD/EUR/CNY/GBP/JPY，日期为YYYY-MM-DD，金额用精确十进制运算。报告SHA-256只用于校对文件，不是签名、法律结论或履约批准。
