# Local material source formats

The importer uses the official [W3C WebVTT format](https://www.w3.org/TR/webvtt1/#file-structure) and [cue timing syntax](https://www.w3.org/TR/webvtt1/#webvtt-cue-timings). Timestamps are `mm:ss.mmm` or `hh:mm:ss.mmm` with at least two hour digits. Minutes/seconds are 00–59; end must exceed start; start times cannot regress, but overlapping cues and equal starts remain valid. BOM, CR/LF, cue identifiers, multiline payloads and cue settings are consumed. Generated evidence IDs retain repeated cues separately; styling, regions and comments are discarded. Cue markup becomes plain text; strings must be displayed with `textContent`, never `innerHTML`. No source URL, CSS or media is loaded, and no ASR is performed.

Plain text input and aggregate evidence text are limited to 4000 UTF-16 code units. Individual evidence text is at most 500 units, with at most 40 spans. Text splitting packs complete logical lines and preserves whitespace, CR/LF separators and surrogate pairs. A logical line longer than 500 units is explicitly rejected: splitting a field value into independently interpreted evidence could otherwise turn `quantity: 10` into `quantity: 1`. A 500-unit line remains intact; its following separator may be placed at the start of the next span. VTT raw input is limited to 32 KiB UTF-8, including ignored metadata; OCR raw JSON is limited to 16 KiB UTF-8. Source/span IDs are limited to 80 units, labels to 120 and engines to 160. Capacity failures reject the source rather than truncate it.

Default source IDs are stable hashes of source kind, role, label and raw content digest. Identical materials imported as a contract and an order, or with different labels, therefore have distinct identities while retaining the same content digest. Explicit source IDs remain unchanged. Span IDs are scoped to their source; references require both source ID and span ID.

OCR consumes strict `office-document-analysis-v1` analysis JSON. Declared provider engines are formatted `kind:name@version`, with fixture declarations explicitly marked `fixture:…`. Pages must be integers from 1 to 3; span pages cannot exceed the declared original page count. Regions use normalized `[x,y,width,height]`, positive dimensions and must fit within the page. Original and import digests are SHA-256; import digests cover the exact supplied UTF-8 input before parsing/normalization.

An optional locally computed original digest can establish equality with the upstream declaration. It does not establish recognition quality or provider authenticity. `validateMaterialSource` checks structure and source-kind contracts, returning a detached validated value; client-supplied engine/hash/verification flags remain declarations, not a server attestation. The flattened source contract has no declared page-count field, so server revalidation can only enforce its 1–3 page range; the importer additionally verifies against the upstream page count.
