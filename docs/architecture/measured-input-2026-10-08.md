# 物品、规格与计量单位入参

用户在生产输入“给行政买一打a4纸”时，旧版拒绝未知品类和“一打”，并把 A4 中的 4 当作数量。这次按输入合同修复，不继续追加物品白名单。

- 普通设备、耗材和用品以物品名称登记，名称最长 64 字；只对整个名称做已知别名归一，不把“打印机墨盒”变成“打印机”。保留规格、型号数字和字母。
- 仅从“数字 + 计量单位”或明确数量标签提取数量，不扫描整句中的所有数字。支持中文整数 1–100；单位独立入参。件为旧版默认单位。
- 一打登记为 1 打，两包登记为 2 包。不假设包装内数量，不把一打纸猜成 12 张或 12 包。分数、约数、范围或多个计量需要补全确认。
- 单条和批量使用同一提取器、格式化器、语义键；语义键包括单位。缺项保留原话和已识别字段，提供名称、数量、单位补全。
- 仅生成未批准草稿。确认绑定名称、规格、数量、单位的哈希；固定表单执行并独立查询 API，未新增付款、外部链接或权限动作。
- 新表单适配器为 v2：名称输入框和可选单位下拉框，DOM 和 POST 仍严格校验。旧批准不能在新适配器下执行，须刷新计划并重新确认。
- 旧的无单位载荷保持原规范 JSON 字节和 v1 九字段证明。显式单位的证明为 v2，增加单位校验；核对包同时接受 v1/v2。D1/SQLite JSON 记录，无数据迁移；保留十条历史记录。
- 不承诺任意自然语言均能自动理解；有界提取失败时用结构化补全。生产仍标记有界规则来源，模型未启用。
